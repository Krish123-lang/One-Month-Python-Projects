# 🟢 BASIC (Beginner-Friendly, Core Concepts)
🔹 Focus on: Loops, conditions, functions, basic data structures.
🔹 Goal: Strengthen fundamentals, break problems into steps.

1️⃣ Number Guessing Game – User guesses a random number; program gives hints.

2️⃣ Basic Calculator – Perform +, -, *, / with user input.

3️⃣ To-Do List (CLI) – Add, remove, and display tasks in a list.

4️⃣ Rock-Paper-Scissors – Play against the computer (random choice).

5️⃣ Word Counter – Count words and characters in user-inputted text.

6️⃣ Temperature Converter – Convert between Celsius, Fahrenheit, and Kelvin.

7️⃣ Even-Odd Number Checker – Take input, determine if it’s even or odd.

8️⃣ Prime Number Checker – Check if a number is prime.

9️⃣ Simple Login System – Take username & password, verify stored credentials.

🔟 Multiplication Table Generator – Print tables up to a given number.

✅ Outcome: You’ll master loops, conditions, and functions.
