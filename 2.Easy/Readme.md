# 🟡 EASY (Getting Comfortable, Simple Logic)
🔹 Focus on: Arrays, lists, loops, string manipulation.
🔹 Goal: Work on data handling and user interaction.

1️⃣ Fibonacci Sequence Generator – Print the first N Fibonacci numbers.

2️⃣ Palindrome Checker – Check if a word or number reads the same backward.

3️⃣ Factorial Calculator – Find the factorial of a given number.

4️⃣ Anagram Checker – Check if two words are anagrams of each other.

5️⃣ Age Calculator – Take birth year, output current age.

6️⃣ Hangman Game (CLI) – Guess letters in a word before running out of attempts.

7️⃣ Simple ATM System – Withdraw, deposit, and check balance.

8️⃣ Random Password Generator – Generate secure passwords with mixed characters.

9️⃣ Text-Based Adventure Game – User makes choices in a simple text RPG.

🔟 Basic CRUD App (CLI) – Create, read, update, and delete notes.

✅ Outcome: You’ll get stronger with loops, conditions, and handling user input.
